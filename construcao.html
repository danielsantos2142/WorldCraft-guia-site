Pá de Pedra

🏠 Guia: Casa Inicial

Sua primeira casa é vital para a sobrevivência. Deve ser compacta, segura contra Creepers e ter espaço para cama, fornalha e baú. Use madeira e pedregulho para uma construção resistente.

🏗️ Estrutura

  • Base: 7×9 blocos nivelados
  • Paredes: 3-4 blocos de altura
  • Telhado: Escadas e lajes
  • Fundamento: Pedra ou madeira

🛠️ Materiais

  • 64x Tábuas de Madeira
  • 32x Pedregulho
  • 16x Vidro
  • 8x Tochas/Lanternas
  • 1x Porta de Madeira

🎯 Essenciais

  • Cama para definir spawn
  • Baú para armazenamento
  • Fornalha para cozinhar
  • Mesa de Trabalho

💡 Dicas de Segurança

🛡️

Proteção Perimetral

Construa uma cerca de 2 blocos de altura ou um fosso ao redor da casa para impedir mobs.

💡

Iluminação Estratégica

Coloque tochas a cada 6-8 blocos para prevenir spawn de mobs hostis na área.

🚪

Entrada Segura

Use portas de ferro ou construa um saguão com duas portas para proteção extra.

🏃

Rota de Fuga

Sempre tenha uma saída secreta ou alternativa para emergências.
